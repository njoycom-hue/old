# 두뇌톡톡 (초안)

치매 예방을 돕는 두뇌 훈련 웹 앱 초안입니다. 별도 설치나 빌드 과정 없이 정적 HTML/CSS/JS로 동작합니다.

## 포함된 게임

- **기억력 카드 짝맞추기**: 같은 그림 카드를 찾는 기억력 게임
- **순서 기억하기**: 점점 길어지는 순서를 그대로 따라 누르는 게임 (사이먼 게임 방식)
- **빠른 암산**: 간단한 덧셈/뺄셈 객관식 문제 10문항
- **다른 것 찾기**: 같은 범주가 아닌 낱말을 찾는 인지 훈련 문제 10문항

각 게임의 최고 기록은 브라우저의 `localStorage`에 저장되어 홈 화면에 표시됩니다.

## 실행 방법

빌드 도구가 필요 없습니다. 저장소 루트에서 정적 서버를 띄우고 브라우저로 열면 됩니다.

```bash
python3 -m http.server 8000
# 이후 http://localhost:8000 접속
```

또는 `index.html`을 브라우저로 직접 열어도 됩니다.
